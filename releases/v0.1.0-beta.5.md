# Humming 0.1.0-beta.5

## A sharper floating launcher

This maintenance beta improves the default on-screen Humming button. The familiar leaf symbol now renders from a dedicated 256-by-256-pixel artwork resource instead of stretching the smallest frame inside the app's ICO. Edges look noticeably clearer at common Windows display scaling levels.

### What changed

- A high-resolution built-in image replaces the low-resolution default frame used by the floating button.
- The floating button and Preferences preview use high-quality image interpolation.
- The right-click menu now uses the active light/dark background and contrasting text, with readable hover and separator styling.
- Clicking the small floating icon opens the centered search panel by smoothly expanding from that icon. When background mode is on, dismissing the launcher reverses the transition into the floating circle.
- Fixed the previous animation's shaking: the new transitions draw on a single stationary canvas rather than resizing and moving a transparent window on every frame. Opening takes about 260 ms; returning takes about 230 ms.
- Reduce motion and high-contrast settings bypass the morph. Keyboard hotkey opening remains brief.
- Humming's existing application and notification-area ICO are unchanged.
- User-selected private pictures, metadata stripping, saved placement, edge docking, click-to-open, themes, keyboard shortcuts and optional startup retain their previous behavior.

### Privacy, upgrade and limitations

Humming works locally without an account, telemetry, automatic updater or license server. Custom floating pictures and their metadata-free thumbnails remain in your own settings and are not bundled in downloads.

Quit the currently running Humming process before installing this update. Setup retains the per-user data folder; portable users should keep their existing `data/` folder while replacing application files. The app and installer are unsigned.

This release focuses on floating-launcher artwork, menu readability and smoother open/close motion. The exact beta.4-to-beta.5 Setup upgrade has not been fully exercised against a separate clean Windows profile; back up your local settings before updating. Broader accessibility, mixed-monitor DPI, slow drives, separate clean-machine compatibility and Everything-equivalent indexing remain outside this beta's validated scope.
