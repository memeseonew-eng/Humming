# Humming 0.1.0-beta.6

## Your global hotkey now unfolds Humming from the floating button

This maintenance beta fixes an inconsistent animation: clicking the small floating Humming button already expanded the full launcher smoothly, but **Ctrl+Alt+Space** opened the launcher without that transition. Now the two actions feel the same.

### What's fixed

- With the floating button visible and Humming's main window hidden, pressing **Ctrl+Alt+Space** opens with the *same* approximately 260 ms circular expansion used by clicking the button. The launcher opens on the floating icon's monitor, even if the pointer is elsewhere.
- Pressing the shortcut while Humming is open continues to dismiss the window with the smooth reverse animation, returning to the floating icon.
- If the floating button is disabled, hidden or unavailable, the shortcut retains its ordinary launcher opening. It never animates from an invented screen position.
- The stable fixed-canvas animation introduced in beta.5 remains unchanged; no repeated resizing of a transparent native window.
- The action respects Reduced Motion, High Contrast, the user's selected floating picture, edge position, and hotkey customization. Background/Windows startup defaults and private settings are unchanged.

### Local data, upgrade and limitations

Humming runs locally without an account or telemetry. The optional floating image is downscaled and stripped of original metadata before being saved privately. Release downloads contain no personal settings or filename index.

Quit your existing Humming instance before updating. Windows Setup retains the existing installed profile; for portable ZIP updates, keep your existing `data/` folder while replacing the program files. The application and Setup are unsigned, and updates are manual.

The release was verified with component, protected-binary/privacy and focused hotkey animation tests. A complete prior-version Setup upgrade on an isolated, clean Windows user profile, full legacy UI sweep, mixed-monitor DPI, accessibility and extended idle testing remain separate verification gaps; backing up your settings before upgrading is recommended. This version does not claim Everything-equivalent indexing.
